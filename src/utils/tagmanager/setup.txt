Step 1 — Keep OneTrust Consent in Your Codebase

✅ You already have this — perfect.
	•	OneTrust controls whether users allow cookies/tracking.
	•	It must load before any analytics or marketing tags.
	•	No need to put it in GTM. Just make sure it’s running as part of your Next.js app, early in the page.

⸻

Step 2 — Setup GA4 Configuration in GTM
	1.	Go to GTM → Tags → New → GA4 Configuration
	2.	Enter your GA4 Measurement ID
	3.	Turn off “Send pageview event on load”
	•	We’ll fire pageviews manually so we don’t double-count in SPA navigation.
	4.	Trigger: Initialization → All Pages
	•	This ensures GA4 config loads immediately.

Why: The config must exist immediately, but we control when the actual pageview fires.

⸻

Step 3 — Capture UTMs & Referrer
	1.	Inside GTM, create Variables:
	•	Page URL → built-in
	•	Page Path → built-in
	•	Referrer → built-in
	•	Optional: Capture utm_source, utm_medium, utm_campaign from URL
	2.	We’ll send these along when firing the pageview manually.

⸻

Step 4 — Fire Pageview Manually (SPA-Friendly)

Because Next.js App Router doesn’t reload the page on navigation, we need to push a pageview every time the route changes.

Steps for Next.js:
	1.	Create a small React component (you can call it GA4PageTracker)
	2.	Paste this code:

"use client";
import { usePathname, useSearchParams } from "next/navigation";
import { useEffect } from "react";

export default function GA4PageTracker() {
  const pathname = usePathname();
  const searchParams = useSearchParams();

  useEffect(() => {
    window.dataLayer = window.dataLayer || [];
    const url = pathname + (searchParams?.toString() ? `?${searchParams}` : "");

    window.dataLayer.push({
      event: "virtual_pageview",
      page_location: window.location.href,
      page_path: url,
      page_title: document.title,
      page_referrer: document.referrer,
    });
  }, [pathname, searchParams]);

  return null;
}


3.	Mount this once in your root layout (so it runs on every route change).

Why: This ensures GA4 receives one pageview per route, no duplicates.

⸻

Step 5 — Setup Marketing Tags Delay

All heavy third-party tags (Meta, TikTok, LinkedIn, Reddit, VWO, Clarity, StackAdapt):
	1.	In GTM, create a Custom Event Trigger called marketing_ready
	2.	For each heavy tag, replace their triggers with marketing_ready
	3.	In your Next.js app, push the event after a delay or user interaction:

"use client"; // very important
import { useEffect } from "react";

export default function MarketingTrigger() {
  useEffect(() => {
    const fireMarketing = () => {
      window.dataLayer = window.dataLayer || [];
      window.dataLayer.push({ event: "marketing_ready" });
    };

    // Fire automatically after 4 seconds
    const timer = setTimeout(fireMarketing, 4000);

    // Fire early if user interacts
    window.addEventListener("click", fireMarketing, { once: true });
    window.addEventListener("scroll", fireMarketing, { once: true });

    // Clean up on unmount
    return () => clearTimeout(timer);
  }, []);

  return null; // This component renders nothing
}


Why:
	•	GA4 fires immediately → accurate tracking
	•	Heavy tags fire after delay or user interaction → better CWV
	•	You still capture most sessions without losing initial pageview

GTM Tag Setup for Form Submit

Inside GTM:
	1.	Create a Trigger → Custom Event → form_submit
	2.	Create a GA4 Event Tag:

	•	Event Name: form_submission
	•	Parameters:
	•	form_name → {{form_name}}
	•	utm_source → {{utm_source}}
	•	utm_medium → {{utm_medium}}
	•	utm_campaign → {{utm_campaign}}

	3.	Trigger the GA4 Event on the form_submit event from dataLayer

✅ Now every form submission tracks:
	•	Which campaign drove it
	•	Source/medium
	•	Form name

⸻

5️⃣ Summary in Plain English
	1.	Page Load: Capture UTMs → store in cookies → persists across site
	2.	GA4PageTracker: Tracks pageviews with SPA support
	3.	MarketingTrigger: Fires heavy marketing pixels later
	4.	Form Submit: Reads cookies → sends event with UTMs to GTM / GA4

This guarantees:
	•	Paid campaign attribution is preserved
	•	You don’t lose short sessions
	•	CWV stays high (no extra JS blocking)
	•	Forms are linked to campaigns automatically



"use client";
import { useEffect } from "react";

export default function MarketingTrigger() {
  useEffect(() => {
    const fireMarketing = () => {
      // Ensure this only fires once
      if (window.marketingFired) return;
      window.marketingFired = true;

      window.dataLayer = window.dataLayer || [];
      window.dataLayer.push({ event: "marketing_ready" });

      // 🔹 Load guarded scripts here directly if needed
      loadTikTokPixel();
      loadRulerScript();
      loadMetaPixel();
      loadLinkedInPixel();
      // Add other heavy scripts similarly
    };

    // Fire after 4s or on user interaction
    const timer = setTimeout(fireMarketing, 4000);
    window.addEventListener("click", fireMarketing, { once: true });
    window.addEventListener("scroll", fireMarketing, { once: true });

    return () => clearTimeout(timer);
  }, []);

  return null;
}

  if (!window.ttq) {
    !(function (w, d, t) {
      w.TiktokAnalyticsObject = t;
      var ttq = (w[t] = w[t] || []);

function loadRulerScript() {
  if (!window.rulerScriptLoaded) {
    window.rulerScriptLoaded = true;
    (function(d, s, id){
      var js, rjs = d.getElementsByTagName(s)[0];
      if (d.getElementById(id)) return;
      js = d.createElement(s); js.id = id; js.async = true;
      js.src = "https://cdn.ruleranalytics.com/ruler.min.js";
      rjs.parentNode.insertBefore(js, rjs);
    })(document, "script", "ruler-js");
  }
}
