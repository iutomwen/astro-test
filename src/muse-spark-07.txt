Generate the Student Homework Portal View (`src/app/dashboard/student/assignments/page.tsx`), the individual assignment interactive workspace (`src/app/dashboard/student/assignments/[id]/page.tsx`), and its accompanying Vinext edge API route handler (`src/app/api/student/assignments/submit/route.ts`). ### 2. INTERACTIVE WORKSPACE (`/assignments/[id]/page.tsx`)

- Dual-Pane Layout:

### 3. VINEXT EDGE ROUTE SUBMISSION HANDLER
In the backend API handler file, enforce strict edge safety rules:
- Runtime Environment Setup: Use exactly: `import { env } from "cloudflare:workers";` and instantiate Drizzle using `const db = drizzle(env.DB);`.
- Access Control & Session Verification: Validate the incoming better-auth session. Ensure the authenticated user's role is strictly checked as 'student' or 'admin'. - Payload Processing: Accept `assignmentId` (string) and `answers` (Array<{ questionId: number, studentResponse: string }>). Ensure fields are sanitized against injection vectors.
- Transactional Execution: Validate that the submission timestamp sits securely ahead of the designated assignment deadline. If valid, commit the final array payload permanently into the D1 `homework_submissions` table, purge the ephemeral draft payload out of Cloudflare KV, and instantly flip the assignment visibility flag to 'Submitted'.
